2. An image outside the document

An Image is a real detached element with width, height, alt text and attributes. It stays outside document.images and document ID lookup. Connecting newly created images is not implemented yet.

Waiting for Image checks.

Dynamic image fetching is not implemented. Assigning a source here leaves complete false, natural size zero and currentSrc empty. No successful load event is invented.

3. Navigator properties owned by a script

A script can add a value or helper function to navigator and remove it afterward. Actual browser facts such as userAgent remain protected.

4. An honest beacon result

The native sendBeacon method currently declines every request and returns false. That means no data was queued; it does not mean a server received anything.

Waiting for the declined-queue check.

An HTTP copy uses its own origin. A local-file copy uses a loopback URL only as a value for validation. ChezCat performs no request in either case. Ctrl+I reports the declined count without the payload.

5. Two finite script jobs

Two separate classic scripts each count to 6,000. Both should finish. Every script has its own execution allowance, and the page also has an aggregate startup limit.

7. What 0.32 adds

Supported createElement/createTextNode and appendChild/insertBefore/removeChild operations maintain real parent, sibling and connected-state relationships. Live tag collections expose indices, length, item and namedItem. Unique named forms and their owned controls can be found, and a supported control's focus method requests actual browser focus. Parsed script elements expose their nonce without rendering their contents or running again.

  • DOM growth remains bounded to 256 added nodes, depth 128 and 1 MiB. Connecting new controls, images or styles and arbitrary HTML injection remain unavailable.
  • HTTP and document.cookie share memory-only, exact-host cookies with Path, expiry, Secure, HttpOnly and conservative SameSite checks. Nothing is saved to the profile; local/internal documents have no cookie store.
  • Supported Location writes and assign/replace/reload queue same-origin HTTP(S) navigation after the script job, with origin and request-blocker checks at every request/redirect hop. Created external classic scripts use actual requests with the existing origin, CSP, blocker, MIME and source-size limits.
  • Pending script loads delay the final window load; their completion handlers run first. Stop or replacement navigation cancels stale work. Dynamic inline scripts, modules and LINK stylesheet loading remain unsupported.
  • Assignment/ternary parsing now permits 4,096 pending frames. Recursive syntax stays at 64 levels, evaluation at 128 and calls at 32. Supported operators, numeric/string helpers and Error conversion use ordinary valueOf/toString behavior; full ECMAScript conversion remains incomplete.

These notes describe supported subsets, not additional checks run by this workshop. The existing object/query checks above still exercise their original behavior.

8. Capture the page and its actual activity

ChezCat.exe URL --activity-report activity.txt --save-source page.html --wait-ms 2500

--save-source writes the displayed document's original decoded source as UTF-8, before script DOM changes. It works alone or with a report/render, after the optional bounded wait. Failed navigation creates no source file; a diagnostic report can still be saved with a nonzero exit status. Use distinct output files. These headless runs ignore the personal profile unless a profile directory is explicit, and never read or write saved history.

The User-Agent is ChezCat/0.32. Private Google homepage replay advanced past element creation, HEAD lookup and named forms, then reached unsupported LINK behavior, two cross-origin gstatic script requests and an oversized same-origin XJS source. That one captured HTTP 200 asset was 128,525 encoded bytes and 369,762 decoded bytes, exceeding the 64 KiB per-script and 256 KiB combined-source limits. Loopback replay changed the origin/cookie context, used no images and returned 404 for uncaptured paths. The separate live Search attempt returned HTTP 429/CAPTCHA and was not retried or bypassed. Google Search is not verified end to end.
