Send values in a POST.

A native HTML form. No JavaScript is needed.

Start the optional demo server

Run Run-Http-Demo.cmd, leave that terminal open, and open this page over local HTTP. The local-file copy supports editing and reset, but submission needs the demo server.

For encrypted loopback testing, use the HTTPS demo launchers and open the HTTPS copy.

Try the request

The result page should report POST and show the received values. The chosen button supplies the action value; an unchecked checkbox supplies no details entry. POST places these values in the request body.

POST does not itself encrypt a request. The HTTP demo is unencrypted loopback traffic; the HTTPS demo uses the browser's TLS implementation.

Submit by clicking a picture

These are native HTML image buttons using drawings from this project. Click different positions to send the selected button's coordinates to the same local request report.

Palette drawing

Reports palette.x and palette.y.

Enlarged grid

Reports grid.x and grid.y. This drawing is displayed at 144 by 144 CSS pixels.

This button deliberately has no picture. Its alt text supplies the visible fallback:

Only the chosen picture supplies coordinates. They are CSS-pixel offsets from the displayed image's top-left corner; resizing the picture changes its coordinate range. Browser zoom does not turn them into screen-pixel coordinates.

For a keyboard check, reload this page, Tab to an image button, and press Enter. Its initial coordinates are 0,0. Clear the required note and try again to check that validation stops the request. This workshop uses no JavaScript.
