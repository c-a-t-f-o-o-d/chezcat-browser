What this exercises

This original game uses ordinary HTML elements, CSS positioning, real keyboard events, and requestAnimationFrame. F12 opens the inspector while the game is running.

This is a first game foundation. Canvas, WebGL, WebGPU, audio, gamepads, pointer lock and WebAssembly are still separate features to implement. Modern game engines will need those larger systems.
