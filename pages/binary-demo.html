1. One buffer, several views

The middle view covers bytes 4 through 7 of a twelve-byte buffer. Changing its first element changes the same byte in the whole view. A slice keeps its own copy.

Waiting for buffer views.

ArrayBuffer, Uint8Array, byteOffset, byteLength, subarray, slice and indexed writes.

2. Read a number in either byte order

A DataView writes the number 4660, or hexadecimal 1234, into bytes 0 and 1. Reverse its byte order and the whole view changes immediately.

Waiting for DataView.

DataView uses big-endian ordering by default; passing true selects little-endian ordering.
