Text decoding

UTF-8   Windows-1252   ISO-8859-1

Page fonts supply available Unicode glyphs. The original bitmap fallback covers printable Latin-1 and Windows-1252 punctuation; unavailable characters use visible fallback boxes. Complex-script shaping is still limited.

Error handling

These links deliberately exercise errors. A useful error or readable error-status page is expected.

  • 404 with an HTML body
  • 500 with an HTML body
  • An endless redirect loop
  • A redirect to a public HTTPS site (requires a compatible certificate and server)
  • A forbidden redirect from HTTP into a local file
  • A body shorter than its Content-Length
  • Invalid chunk framing
  • Conflicting Content-Length headers
  • An unsupported charset label
  • A gzip checksum mismatch
  • Gzip that expands past the document limit
  • Raw DEFLATE without the required zlib wrapper
  • Brotli content, not implemented yet
