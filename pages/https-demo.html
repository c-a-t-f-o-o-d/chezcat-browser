HTTPS with two versions.

This page, its stylesheet and the image below travel through the browser's own TLS implementation.

TLS 1.3 supports ChaCha20-Poly1305 and AES-GCM. This local TLS 1.2 demo uses ECDHE with AES-GCM and Extended Master Secret. Both verify supported RSA/ECDSA certificate chains.

Run Run-Https-Demo.cmd. It starts this server and opens a new browser window with the separate demo-roots.pem trust file. The server defaults to a P-256 certificate.

For TLS 1.2, run Run-Https-Demo.cmd --tls-version 1.2. To keep the two steps separate, add --server-only, then run Run-Https-Browser.cmd. A normal browser window intentionally does not trust these test certificates.
