# Original binary64 radix witnesses

Generated by tools/generate_number_radix_reference.py using Python standard-library
Fraction and adjacent binary64 values. No browser output or page code is used.
For each digit count, solve the entire integer coefficient interval on that radix
grid; choose the first nonempty grid, closest coefficient, then even on a tie.
This differs from production's incremental remainder/margin digit generation.
Exact midpoint inclusion follows binary64 round-to-nearest/ties-even. MAX_VALUE
uses the virtual next finite grid point to establish its overflow boundary.
An estimate of the initial exponent is corrected by exact rational comparisons.

The frozen TSV covers every nondecimal radix, deterministic finite bit patterns,
subnormals, normal boundaries, adjacent values, huge integers and negative values.
Decimal formatting is existing code and is tested separately. Ordinary Node
examples may be useful controls but large arbitrary-radix output is not used as
an authoritative exact-interval oracle.

Specification: https://tc39.es/ecma262/2025/multipage/ecmascript-data-types-and-values.html#sec-numeric-types-number-tostring
