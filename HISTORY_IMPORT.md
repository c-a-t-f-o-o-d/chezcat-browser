# Imported development history

The public source lineage retains authentic code/test changes, ordering, dates
and contributor metadata. Operational/private records, real-site captures,
compiled application binaries and caches were excluded. A trailing private icon
generation brief was removed while provenance and artwork remained. This does not
establish a human-only development method; automated coding assistance was used.

The existing public repository initialization is a parent of the local integration
lineage. It was not replaced, force-pushed or recreated. The filtered lineage was
merged only after exclusion review, never by merging raw private ancestry.

Rewriting changes commit IDs. Original CI results/signatures do not cryptographically
authenticate the rewritten hashes. Clean tip builds/tests establish their own
identities. Original-to-filtered mapping and sensitive review records are private
review materials, not source-package contents. Retained contributor metadata remains part of the authentic engineering record;
.mailmap does not remove historical objects.

Keep one clean product lineage. Future private WIP may descend
from it; never merge the unsanitized development repository back into it.
